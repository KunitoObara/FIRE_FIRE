FIRE-FIRE

HTMLモック一覧

docs/screen-list-and-transitions.md の画面一覧・遷移図に基づくHTMLモックです。各カードから各画面を確認できます。 認証系(A1〜A8)は中央寄せ1カラムレイアウト、ログイン後(B1〜B10)は共通ヘッダー/サイドバーのダッシュボードアプリ型シェルです。

ログアウトは画面IDを持たない共通操作です(screen-list-and-transitions.md 2.6)。B1〜B10 のどの画面でも、ヘッダー右上のアバターからユーザーメニューを開いて実行できます。

認証系画面(A1〜A8)

A1 サインアップ画面 メール・パスワード入力、パスワードポリシー表示 A2 メールアドレス確認待ち画面 確認メール再送導線 A3 2FA登録画面 QRコード表示、確認コード入力、リカバリーコード A4 ログイン画面 メール・パスワード入力 A5 2FA検証画面 確認コード/リカバリーコード切替 A6 パスワードをお忘れの方画面 リセットメール送信 A7 パスワード再設定画面 新パスワード設定、リンク無効時の表示 A8 アカウント連携画面 Googleログイン時の既存アカウント連携

Googleソーシャルログインの導線は A1・A4 に「Googleで続ける」ボタンとして追加しています(新規画面ではありません)。

A2・A3 の「別のアカウントでログイン」は、サインイン済みだが手順が未完了の状態から抜けるためのログアウト導線です(screen-requirements-auth.md 3章)。ログアウト後は A4 に「ログアウトしました」が表示されます。

ダッシュボード・データ管理系画面(B1〜B4)

B1 ダッシュボード画面 資産推移・分類内訳・FIRE達成度・収支サマリ B2 CSV取込画面 取込種別タブ、プレビュー、完了通知 B3 収支明細一覧画面 絞り込み・並び替え(参照専用) B4 資産分類マスタ設定画面 分類の追加・編集・削除禁止確認

不動産管理系画面(B5〜B7)

B5 不動産一覧画面 登録済み物件の一覧 B6 不動産詳細画面 利ざや自動計算(参照専用) B7 不動産登録・編集画面 収益物件チェックで賃貸収支欄を切替

FIRE目標・シミュレーション設定系画面(B8〜B9)

B8 FIRE目標設定画面 直接入力/逆算タブ切替 B9 想定利回り・リスク設定画面 一覧内インライン編集

アカウント系画面(B10)

B10 アカウント設定画面 パスワード変更・2FA再設定
