# 画面要件定義書:FIRE目標・シミュレーション設定系画面(B8〜B9)

## 1. 位置付け

本ドキュメントは [画面一覧・画面遷移図](./screen-list-and-transitions.md) 2.4節のFIRE目標・シミュレーション設定系画面(B8〜B9)について、画面ごとの要件を詳細化したものである。機能全体の方針は [FIRE-FIRE 要件定義書](./fire-asset-management-requirements.md) 4.6〜4.7節を参照。

## B8. FIRE目標設定画面

- **画面目的**: FIRE達成目標を設定する。目標資産額の直接設定、または年間支出額からの逆算を切り替えて設定できる

| 区分 | 項目 |
|---|---|
| 表示項目 | 現在有効な設定方式、現在資産額との比較(参考表示。対象分類名を併記) |
| 入力項目 | 達成度の対象分類(タブ共通) / 【直接入力タブ】目標資産額 / 【逆算タブ】想定年間支出額、逆算係数(4%ルール等、デフォルト値ありで編集可能) |
| 主な操作 | 達成度の対象分類の選択、タブ切替(直接入力 / 逆算)、「保存」ボタン |

**遷移条件**

- タブ切替時、切替前に入力した値は両タブとも保持される(タブを行き来しても値は消えない)
- 保存成功 → **B1 ダッシュボード画面** へ遷移し、FIRE達成度ゲージ/到達予測日に反映結果を確認できる
- 未入力・数値形式不正等のバリデーションエラー → インラインエラー表示、遷移しない

**達成度の対象分類**

達成度の分子(現在資産額)をどの資産の範囲で数えるかを、[B4 資産分類マスタ設定画面](./screen-requirements-dashboard.md#b4-資産分類マスタ設定画面) で登録した分類軸から選ぶ。設定した範囲は [B1](./screen-requirements-dashboard.md#b1-ダッシュボード画面) のFIRE達成度ゲージと、この画面の参考表示の両方に効く。

- 選択肢は「**総資産(マネーフォワードの合計)**」+ B4で登録済みの分類軸。既定は「総資産(マネーフォワードの合計)」とし、未設定の状態がこれに当たる
- **タブの外に置き、両方式で共通の設定とする。** 目標資産額の決め方(直接入力/逆算)と、比較する資産の範囲は別の話であり、方式ごとに別々の対象分類を持つと切り替えたときに達成率が理由なく変わる
- 保存先はFIRE目標と同じドキュメント(`users/{uid}/settings/fireGoal`)とする。目標額と対象分類は「何に対する目標か」を1組で表すもので、別々に保存すると片方だけ古い状態になりうる
- 参考表示の現在資産額・達成率には**対象分類名を併記する**(例:「現在資産額 49,600,000円(投資性資産)」)。B1のゲージと同じ値・同じ表記にし、画面によって違う数字が出ないようにする
- B4に分類軸が1件も無い場合(CSV未取込等)は「総資産(マネーフォワードの合計)」のみを選べる状態にし、B4への導線を添える。分類軸が無いこと自体はエラーではないため、保存はできる
- 保存済みの対象分類がB4で削除されていた場合は、画面を開いた時点で「総資産(マネーフォワードの合計)」を選択した状態に戻し、その旨を表示する。存在しない選択肢を選択中として出すことはできず、黙って戻すと設定し直したことに気付けないため
- 選択肢からの選択なので入力形式のエラーは発生しないが、保存時に存在しない分類軸IDが渡された場合は保存を拒否する
- 対象分類を変えても目標資産額(直接入力・逆算のいずれも)は変わらない。変わるのは達成率と到達予測日だけ
- 対象分類に**負債を集計対象に含む分類軸**([B4](./screen-requirements-dashboard.md#b4-資産分類マスタ設定画面))を選んだ場合、現在資産額は負債控除後の額になる。「現在資産額」というラベルは分類軸によって出し分けず、何を数えた額かは併記する対象分類名で示す(B1のゲージと同じ扱い)。既定の「総資産(マネーフォワードの合計)」に負債は含まれない — マネーフォワードが負債をCSVに出力しないため、負債を達成度に効かせるには負債を含む分類軸を作って選ぶ必要がある
- 負債が資産を上回って現在資産額がマイナスになった場合、**達成率は0%に丸め、現在資産額の金額はマイナスのまま出す**。負債が資産を上回っている旨も添える。丸め方・注記の理由はB1のゲージと同じで、正は [screen-requirements-dashboard.md](./screen-requirements-dashboard.md) B1「負債を含む分類軸の集計」に置く。**この画面で独自に丸め方を決めない** — 同じ設定に対して画面ごとに違う達成率が出るのを避けるため

## B9. 想定利回り・リスク設定画面

- **画面目的**: 個別の資産・口座ごとに想定利回り・リスク値を手動設定する。設定値はシミュレーション(将来予測)の入力パラメータと、ダッシュボードでの可視化の両方に反映される

| 区分 | 項目 |
|---|---|
| 表示項目 | 資産・口座一覧(名称、現在残高) |
| 入力項目 | 資産・口座ごとの想定利回り(%)、リスクレベル |
| 主な操作 | 一覧内でのインライン編集、「保存」ボタン |

**遷移条件**

- 保存成功 → 設定内容が **B1 ダッシュボード画面** のFIRE到達予測計算・リスク可視化に反映される
- 数値形式不正等のバリデーションエラー → インラインエラー表示、遷移しない
