# 画面要件定義書:不動産管理系画面(B5〜B7)

## 1. 位置付け

本ドキュメントは [画面一覧・画面遷移図](./screen-list-and-transitions.md) 2.3節の不動産管理系画面(B5〜B7)について、画面ごとの要件を詳細化したものである。機能全体の方針は [FIRE-FIRE 要件定義書](./fire-asset-management-requirements.md) 4.5節を参照。

## B5. 不動産一覧画面

- **画面目的**: 登録済み物件の一覧表示

| 区分 | 項目 |
|---|---|
| 表示項目 | 物件名、所在地(簡略)、時価、ローン残高 |
| 入力項目 | なし |
| 主な操作 | 「新規登録」ボタン、物件行のクリック |

**遷移条件**

- 「新規登録」ボタン押下 → **B7 不動産登録・編集画面**(新規登録モード)へ遷移
- 物件行クリック → **B6 不動産詳細画面** へ遷移
- 利ざや(時価-ローン残高)は一覧画面には表示せず、B6でのみ表示する

## B6. 不動産詳細画面

- **画面目的**: 物件の詳細情報と利ざやを確認する

| 区分 | 項目 |
|---|---|
| 表示項目 | 物件基本情報、時価、ローン残高、**利ざや(時価-ローン残高、自動計算)**、収益物件の場合は賃貸収入/支出 |
| 入力項目 | なし(参照専用) |
| 主な操作 | 「編集」ボタン、「一覧に戻る」リンク |

**遷移条件**

- 「編集」ボタン押下 → **B7 不動産登録・編集画面**(編集モード、既存値をプリセット)へ遷移
- 「一覧に戻る」リンク押下 → **B5 不動産一覧画面** へ遷移

## B7. 不動産登録・編集画面

- **画面目的**: 物件基本情報・時価・ローン残高・(収益物件の場合)賃貸収入/支出を登録・編集する

| 区分 | 項目 |
|---|---|
| 表示項目 | (編集時)既存の登録値 |
| 入力項目 | 物件名、所在地、時価、ローン残高、「収益物件として登録」チェックボックス、(チェックオン時のみ表示)賃貸収入、賃貸支出 |
| 主な操作 | 「保存」ボタン、「キャンセル」リンク |

**遷移条件**

- 保存成功(新規登録) → **B6 不動産詳細画面**(登録した物件)へ遷移
- 保存成功(編集) → **B6 不動産詳細画面**(該当物件)へ遷移
- 「キャンセル」押下 → 遷移元の画面(新規登録時は**B5**、編集時は**B6**)に戻る
- 必須項目未入力・数値形式不正等のバリデーションエラー → インラインエラー表示、遷移しない
